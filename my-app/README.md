# 诗迹山河 · 运行说明

这是「诗迹山河」MVP，实现「诗词查询 + 展示」功能。诗词原文、译文、注释来自万维易源（ShowAPI）的「唐诗宋词元曲查询」接口。

## 项目结构

```
my-app/
├── index.html   # 前端页面（搜索框 + 诗词卡片）
├── server.py    # 后端服务（Flask，密钥保险柜 + 数据中转）
├── .env         # 本地密钥（appKey，已被 .gitignore 忽略，永不提交）
└── README.md    # 本说明
```

## 架构说明（为什么分前后端）

```
浏览器页面(index.html)
    ↓ 调用本地接口
后端(server.py, Flask)  ← 密钥只在这里，浏览器看不到
    ↓ 拿 appKey 去调
万维易源接口(route.showapi.com)
    ↓ 返回
原文 + 译文 + 注释 → 渲染到页面
```

**关键**：appKey 是账号密钥，绝不能写进前端代码（否则传到 GitHub 会被别人盗刷）。所以用后端做「中转」，密钥只存在本地 `.env`。

## 如何运行

需要**同时启动后端和前端**两个服务。

### 第一步：启动后端（必须）

```bash
cd my-app
python server.py
```

看到 `诗迹山河后端启动中 → http://localhost:5000` 即成功。

> 需要先安装依赖：`pip install flask requests`

### 第二步：启动前端

**方式一：直接双击打开**（最简单）

双击 `my-app/index.html`，浏览器就会打开页面。

**方式二：用本地服务器打开**（地址栏显示 localhost，截图更规范）

```bash
cd my-app
python -m http.server 8000
```

然后浏览器打开 **http://localhost:8000**

## 功能说明

- **诗词查询**：输入诗人姓名（如「李白」「杜甫」「苏轼」），可列出 TA 的全部作品。
- **分页**：作品多时支持翻页（每页 20 首）。
- **展示**：每首诗词展示原文、译文、注释（三件套齐全）、作者、朝代。
- **诗人简介**：搜索诗人时，顶部展示 TA 的生平简介。

## 数据来源

- 诗词数据来自 [万维易源 ShowAPI「唐诗宋词元曲查询」接口（apiCode=1620）](https://www.showapi.com/apiGateway/view/1620)，注册即可免费调用（有防滥用的档次限制）。
- 数据自带「原文 / 译文 / 注释」三件套，无需自己整理。
- 诗词原文属于公有领域（古人作品），无版权问题。

## 密钥安全

- appKey 存放在 `my-app/.env`，此文件已被 `.gitignore` 忽略，**不会上传到 GitHub**。
- 后端通过读取 `.env` 获取密钥，前端代码中不出现任何密钥。
- 换机器或重新克隆代码后，需要重新创建 `.env` 并填入自己的 appKey。

## 技术说明

- 前端：HTML + CSS + JavaScript（纯静态，后续升级 Vue）。
- 后端：Python + Flask（符合 TECH_DESIGN.md 的技术选型）。
- 数据：通过第三方 API 实时获取，暂未引入数据库（数据量小，无需本地存储）。
