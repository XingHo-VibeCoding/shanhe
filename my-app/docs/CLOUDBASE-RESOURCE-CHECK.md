# 诗迹山河 · CloudBase 资源检查任务 + 资源与到期说明

> 用途：定期（建议每月一次、大改数据前一次）人工检查云资源还剩多少、什么时候到期、怎么把数据备份出来。
> 本文件不含任何密钥；密钥清单和存放位置见 `.env`（本地文件，不入库）。

---

## 一、资源检查任务（人工 5 步，全程约 10 分钟）

1. **进环境**：登录腾讯云控制台（console.cloud.tencent.com）→ 顶部搜索「云开发 CloudBase」→ 进入诗迹山河用的环境
2. **看用量**：左侧「概览 / 用量」页，记下并截图：
   - 云函数调用次数（本月）
   - 数据库读 / 写次数
   - 存储用量与 CDN 流量
3. **看到期**：「环境设置 / 套餐管理」页，记下当前版本（免费版 / 基础版）与**到期或重置日期**，截图
4. **导数据**：进入数据库管理，找到打卡相关的表/集合，用「导出」功能导出 JSON 或 CSV 保存到本地
   - 说明：本站数据在 CloudBase 的 PostgreSQL 库（poems、checkins 等表）；若控制台走数据管理工具（如 DMS），用查询结果导出即可
   - 导出文件命名建议：`checkins-YYYYMMDD.json`
5. **查文件存储**：「文件存储」页如有上传过的图片等，记录清单或下载到本地

> 每步都截图（额度、到期日期、用量要同框可见），这就是资源检查的打卡证据。
