## 定位结论（板块②收口）
失败 = 两类触发叠加的「首次请求偶发失败」：
1. **云端后端休眠冷启动**（10:05 实证：闲置 11 小时后首请求返回空，重试即愈）
2. **手机侧连接瞬断**（10:21、12:23 实证：同时刻 PC 成功、手机失败；T1/T2/T3 证明链路与跨域本身畅通；备注：手机后台有直播/视频类浮动窗口持续占用带宽，大响应（单次搜索结果约 260KB）与此叠加易超时）

失败后的「重试」按钮均可恢复——与定位结论自洽。

## 修复记录（板块③，12:54 完成）
1. **前端自动重试**：index.html / home.html / detail.html 各新增 `fetchRetry()`（首次网络失败后 800ms 自动重试一次，仍失败才走中文错误提示），9 个 API 调用点全部替换；`node --check` 三页通过
2. **定时保活**：WorkBuddy 自动化「诗迹山河后端保活」每 10 分钟 ping `/daily` 与 `/famous`（消除后端休眠触发源）
3. 既有「重试」按钮保留作兜底
